# Sounding day archive (skewt-archive branch)

Day bundles for the Skew-T Explorer (scorvec.com/skewt/): one `day-YYYYMMDD.zip` per complete UTC day, each holding
that day's soundings as thinned CSVs (`{station}_{YYYYMMDDHH}.csv`), bundled once a day is three days old. Sources:
Iowa Environmental Mesonet (Iowa State University) RAOB archive for real-time North American soundings, and NOAA NCEI's
Integrated Global Radiosonde Archive v2 (IGRA2) for the rest of the world. Written by skewt-data.yml and fetched by the
browser via raw.githubusercontent.com.
