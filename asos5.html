Sources: NOAA/NWS MADIS HFMETAR (the official 5-minute ASOS feed), the NWS API for stations that do not transmit 5-minute data (KJFK, KNYC — hourly METARs, marked “hourly”), and the official METAR 6-hour max/min temperature groups via the NWS Aviation Weather Center — the same values shown in the 6/24-hr column of the NWS timeseries pages. Card max/min are the absolute extremes since local midnight: the sampled observations merged with any 6-hour group that exceeds them (a 6-hr window straddling midnight is credited to today only when its extreme beats every sample from the pre-midnight part of that window). When an extreme comes from a 6-hr group, the card shows the group’s time window instead of an exact minute. Temperatures pass MADIS QC; obviously bad values are dropped.
