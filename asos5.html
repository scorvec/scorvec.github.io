Click a card to isolate a station (adds dashed max/min reference lines over the shown window) · times are each station’s local clock
Primary source: the official NWS API (api.weather.gov), fetched directly in your browser on every visit — it serves 5-minute ASOS observations for most of these stations and hourly METARs for KJFK & KNYC (marked “hourly”), so the page is always current with no server job in the loop. The daily max/min are the absolute extremes since local midnight: the sampled observations merged with the official METAR 6-hour max/min temperature groups (the 1sTTT/2sTTT remark groups, parsed from each hourly METAR) when those exceed the samples; when an extreme comes from a 6-hour group the card shows the group’s time window instead of an exact minute. As a precision overlay, the 0.1 °C NOAA/NWS MADIS HFMETAR 5-minute feed is layered in when the background updater has posted it recently. When a station is isolated, dashed reference lines mark its max/min over the shown window, taken from the plotted observations and raised to any official METAR 6-hour (1sTTT/2sTTT) or 24-hour (4…) group extreme that catches a peak between samples; each line is tagged by source (sampled / 6-hr / official) and the span it covers, so it always bounds the visible curve. Obviously bad values are dropped.
